# I am good - 3D horror game
A 3D horror game made in Godot. It's a third person game where player controls a wooden stick called "I am good" and tryes to escape from the haunted house.

Game was made using Godot 4 and Blender. 
Language used : Gdscript 

Implemented:
- inventory system
- UI
- player movement
- enemy AI patrol/chase
- each item with unique effects
- hiding
- jump scare
- death animation
- settings
